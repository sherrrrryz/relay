# Relay

Relay <> FoF Activity Kit design project. This repo also holds the start of its design system.

## Structure

| Folder | What goes here |
| --- | --- |
| `research/` | Notes, interviews, references, competitive scans |
| `explorations/` | Sketches, concepts, iterations |
| `assets/` | Exported images, icons, logos |
| `specs/` | Handoff specs, annotations, decisions |
| `tokens/` | Design tokens (colour, type, spacing) — the design system foundation |
| `prototype/` | Simple HTML/CSS prototype — open `prototype/index.html` in a browser |
